# CMO: the marketing standard the competition sets

Scope: how ten frontend-education competitors market themselves across their blogs, newsletters, LinkedIn, X, Instagram, Facebook, YouTube, Hacker News and Product Hunt, and what they pay for. For each: launch stories, audience size per channel, content formats, newsletter practice, cross-posting and canonical URLs, SEO signals, the showcase their campaigns point at, home-page messaging, release playbook, paid boosting, and campaigns with stated results. Written for **elegantfrontend.training**. It teaches frontend terminology (the UI / Server / State layers of the Universal Frontend Architecture) and AI-harness Agent Skills to frontend developers who lost their jobs to AI. The brand accounts are Instagram @elegantfrontend, X @elegantfrontend, YouTube @elegantfrontend, and a LinkedIn page and Facebook page named "Elegant Architecture".

This standard serves the CMO office's agents: a blog agent (no AI slop, syndicated to dev.to, Hashnode and Medium), a weekly LinkedIn newsletter agent, one agent per social network, and an ads agent that boosts posts that are already doing well.

Rules followed:
- Every number carries an evidence ID `[E#]`. Each ID maps to a URL in `## Evidence`, and every one of those URLs was fetched on **2026-10-17**.
- Wayback Machine copies also give their capture date.
- "Raw" X follower counts are the `followers:` value in the HTML that x.com sends before JavaScript runs. X does not display them without JavaScript.
- Anything that could not be fetched sits in `## Unverified` and is never used in `## The bar for our product`.

  - Master.dev: "Learn the Dev Skills to Thrive in the Age of AI" [E36].

### 2. What their best posts have in common
- **One mechanism, explained visually.**

  - GreatFrontEnd runs this as a LinkedIn series ("5 CSS animation pairs…", "5 React pairs…", "5 image and media pairs…").
  - It closes with "Save this before your next React interview" [E22].
