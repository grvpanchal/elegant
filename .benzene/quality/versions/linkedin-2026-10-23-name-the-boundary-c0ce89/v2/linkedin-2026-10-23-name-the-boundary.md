An agent writes the selector. A human names the layer it reads from.

The part of frontend work that survived AI isn't typing. It's naming: which layer a value belongs to, what crosses a boundary, and what "done" means as a test.

An agent can write createSelector in a second. It can't decide whether the filtered list is UI state or server state, whether a selector should return a new reference or the same one, or what test proves the work is done.

That's the vocabulary employers are hiring for now. Not the code. The boundary.

The carousel walks through five terms that sound like one layer but belong to another, and the test that makes "done" something a runner reports, not an opinion.
