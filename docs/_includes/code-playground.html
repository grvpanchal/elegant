{%- comment -%} In-browser practice workspace for a `format: coding` question. Loads /practice/workspace//starter.js into the editor and runs the question's own tests.js against whatever the learner typed. The same tests.js runs under Node in harness/check_harness.py (`workspace.tests_pass`), so the browser and CI agree on what "solved" means. The editor is a textarea with a syntax-highlighted overlay behind it (`data-playground-highlight`), a drag handle to resize it (`data-playground-resize`) and a console pane (`data-playground-console`) that captures console.log output from the learner's code so they do not need devtools to debug. Their styles live in docs/_sass/components/practice.scss with the rest of the workspace. Requires docs/practice/workspace//{starter,solution,tests}.js to exist. {%- endcomment -%}
